# 🚀 AI Career + Finance Copilot for Students (Enterprise Full-Stack System)

An intelligent, full-stack AI Decision Copilot that co-optimizes **Career Placement Readiness** and **Student Financial Affordability**.

---

## 🌟 10 Production-Grade "Make It Real" Capabilities

1. 🎯 **Career Decision Simulator / "What If?" Mode (Killer Feature #2)**:
   - Interactive variable sliders for Study Hours ($1.0 - 6.0$ hrs/day), Monthly Budget (₹$500$ - ₹$8,000$), and Target Role.
   - Course Investment Sandbox: *"What if I spend ₹5,000 on a course?"* $\rightarrow$ Computes Expected Skill Gain (+8%), Readiness Gain (+4%), Financial Stress (HIGH), and free alternatives.
   - Side-by-side Scenario Comparison (Scenario A vs Scenario B vs Scenario C).

2. 📊 **7-Factor Placement Readiness Score & Bottleneck Analyzer**:
   - Comprehensive Score (e.g. 78/100) across 7 critical placement factors:
     - Technical Skills (82)
     - DSA & Algorithms (61)
     - Portfolio Projects (74)
     - ATS Resume Compatibility (68)
     - GitHub Activity (55)
     - Soft Skills & Communication (72)
     - Mock Interview Readiness (63)
   - Explainable Bottleneck Diagnosis: *"Your biggest bottleneck is DSA (61/100). Improving DSA from 4 to 7 could increase readiness by ~9%."*

3. 🧠 **Interactive Skill Dependency Graph**:
   - Topological prerequisite DAG (Python $\rightarrow$ NumPy/Pandas $\rightarrow$ Machine Learning $\rightarrow$ Deep Learning $\rightarrow$ PyTorch $\rightarrow$ FastAPI $\rightarrow$ Docker $\rightarrow$ Target Goal).
   - Real-time status node badges: 🟢 Mastered, 🟡 Learning, 🔴 Missing.

4. 💼 **Live Job-Market Matching & Benchmark**:
   - Real-time hiring demand, median compensation ranges (₹12L - ₹24L/yr), and market skill bars.
   - *"3 skills preventing you from reaching 90%"*: PyTorch, Docker, DSA Algorithm Speed.
   - Live campus openings (Razorpay, Swiggy, Zomato, Jio AI CoE).

5. 📄 **AI Resume Analyzer & Bullet Point Polisher**:
   - Instant ATS compatibility scoring (71/100).
   - Missing high-frequency keyword detection (Docker, REST APIs, PyTorch, CI/CD, AWS).
   - Before $\rightarrow$ After Bullet Point Optimizer:
     - ❌ *"Created a machine learning project for customer churn."*
     - ✅ *"Engineered an end-to-end customer churn prediction pipeline using XGBoost and Scikit-Learn, achieving 89% validation accuracy and serving real-time inferences under 40ms via FastAPI."*

6. 🧪 **Detailed 4-Week Project Blueprints & GitHub Production Checklist**:
   - Step-by-step weekly milestone deliverables (Week 1 to Week 4).
   - Interactive GitHub Production Checklist (☐ README.md, ☐ Unit Tests, ☐ API Docs, ☐ Live Demo link, ☐ Dockerfile).

7. 💰 **Financial "Should I Buy This?" One-Click Evaluator**:
   - Evaluates any paid course, bootcamp, or certification voucher against monthly allowance and learning budget.
   - Calculates exact Affordability %, Career Benefit, Urgency, and Sinking Fund savings timeline.

8. 📈 **Dynamic Trajectory Prediction (Today $\rightarrow$ 1 Mo $\rightarrow$ 3 Mo $\rightarrow$ 6 Mo)**:
   - Dynamic simulation showing how skills compound over time based on daily study hours.

9. 🏆 **Professional Gamification HUD**:
   - 🔥 7-Day Consistency Streak tracker.
   - Level 7 ("Interview Ready") status with XP counter.
   - Verified Milestone Badges (🏅 First Project, 🔥 7-Day Streak, 💻 100 DSA Problems, 📄 Resume Ready).

10. 🔄 **Sunday AI Weekly Career Review**:
    - Automated weekly feedback loop summarizing completed sprints (17/21), study hours logged (11.5 hrs), and skill deltas.
    - AI Counselor narrative and 4 actionable directives for the upcoming week.

---

## 🛠️ Tech Stack

- **Backend**: FastAPI (Python 3.14), Pydantic v2, Uvicorn, REST Endpoints
- **Frontend**: React 18, Vite, Tailwind CSS v4, Lucide Icons, Canvas Confetti
- **AI / ML**: Multi-Criteria Decision Engine, Simulation Trajectories, Weighted Skill Graphs, LLM Intent Service
